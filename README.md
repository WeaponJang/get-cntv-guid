# get-cntv-guid 项目介绍
*************************************************************
## CCTV-HLS-Client.user.js 油猴脚本
### 一个获取 cctv.cn 视频播放页的 GUID 值和 hls 下载链接的油猴脚本
+ 实现了点击右下角按钮获取 guid 的功能,右下角没有按钮的说明不兼容
+ 支持在h5e和enc2接口之间切换,需要手动变更 **switchh5e** 变量
+ H5E接口视频的解密可以用 **https://github.com/WeaponJang/cctv-h5e-downloader** 这个项目

*************************************************************
## CCTV-enc2.user.js 油猴脚本
### 一个只解析 enc2 接口的 m3u8 链接的油猴脚本
+ 从 CCTV-HLS-Client.user.js 分离出来的逻辑,专为 enc2 接口
+ 主要是为了搭配 udrm-dec.cjs 这个 node/bun 脚本
+ ENC2接口的链接需要关闭https校验访问,导致浏览器上无法正常下载,因此可以借助 **N_m3u8DL-CLI-NET8** 这个命令行工具

*************************************************************
## N_m3u8DL-NET8 命令行工具
### 一个m3u8链接下载器命令行版
+ 源码来自 **https://github.com/nilaoda/N_m3u8DL-CLI**
+ 原版基于 .netfx 4.6 ,鉴于运行时不够现代,此版改用 dotnet 8 重构,支持的命令行参数不变
+ **N_m3u8DL-CLI.zip** 是编译产物压缩包,解压出的单文件自包含运行时,可直接在 Win10+ 系统上运行
+ **N_m3u8DL-NET8-src.zip** 是源码的 zip 打包文件,编译至少需要用 DOTNET 8 的 sdk,dotnet 10的SDK尚未测试

*************************************************************
## udrm-dec.cjs nodejs脚本
### 一个解密 enc2接口视频 的工具
- 如果系统中有 ffmpeg 的可执行文件,则输入可以是 mpegts 格式的以 .ts 为扩展名的视频文件
- 解密算法来自 **Tontonnow/cctv-decrypt** 项目中的源码,由c和python组成,因其步骤繁琐,依赖庞杂,故重构之。
- 需要使用node或bun执行这个脚本,不加参数运行之时会显示用法
